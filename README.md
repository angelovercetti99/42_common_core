# 42_common_core

Projects and exercises developed during the Common Core at **Porto 42**, a coding school following a peer-to-peer methodology: no teachers, no lectures, learning through real projects and peer code review.

## About Porto 42

Porto 42 follows the 42 network model, built around:

- **Peer learning** — students learn from each other, with no teachers involved
- **Hands-on projects** — knowledge is built by solving real problems, not memorizing theory
- **Peer evaluation** — every project is reviewed and validated by fellow students, which forces a deep understanding of the code, not just getting it to work
